# BillSphere

BillSphere is an event-driven Subscription Billing & Usage Analytics Platform built using microservices architecture.

## Tech Stack

### Frontend
- React
- Redux Toolkit
- SCSS
- Axios
- React Router

### Backend
- Node.js
- Express.js

### Databases
- PostgreSQL
- MongoDB

### Messaging
- Kafka

### Caching
- Redis

### Security
- JWT Authentication
- Google OAuth
- HttpOnly Cookies
- Rate Limiting

### DevOps
- Docker
- Docker Compose
- AWS EC2 Free Tier

## Microservices

- Frontend Service
- Auth Service
- Billing Service
- Usage Service
